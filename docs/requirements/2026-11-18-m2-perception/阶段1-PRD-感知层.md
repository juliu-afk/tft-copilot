# 阶段1-PRD-M2 感知层（截屏→结构化棋局）

> 批次：2026-11-18-m2-perception | 状态：基线（用户已授权连续执行）
> 上游：工程方案 v1.1 第 3 章 + M1 知识库（rules/units JSON + 122 官方头像模板）

## 1. 背景与用户问题

M1 完成后工具只有"死知识"没有"眼睛"。M2 任务：装上眼睛——从截屏像素提取结构化棋局状态（层数/金币/血量/等级/商店五卡/弈子），供 M3 决策层消费。

前提约束：三红线（零输入模拟/零进程读取/零联网外传）；单帧 ≤150ms、CPU ≤15%。

**验证口径诚实降级**：当前无真机环境，原"200 帧真机标注验证"改为**合成帧引擎验证**，真机验证移交 M6。

## 2. 用户故事

- **US-2 (P0)** 选牌阶段识别商店 5 张卡身份
