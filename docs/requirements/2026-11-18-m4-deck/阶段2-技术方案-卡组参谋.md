## 3. 四维评分引擎

| 维度 | 权重 | 计算 |
|---|---|---|
| 强度曲线 | 0.35 | 卡组三卡效应标签聚合：economy/xp/combat/trait-bridge/sustain |
| 任务兼容 | 0.30 | 与 rules 库 38 任务的关键羁绊交集（members 价格带覆盖任务需求段） |
| 传送门匹配 | 0.20 | 以绪塔尔-术士类桥梁卡（trait-bridge tag） |
| 成型难度 | 0.15 | 三卡平均星级的运营负担（高星卡占比） |

### 评分基数
- 每卡基于名称模式匹配打 effect_tags（如「奖金/金币流」-economy；「传送门」-trait-bridge）
- desc_missing 卡按 tag 骨架参与评分，quality_flags 透明披露

## 4. 组合推演器

### 剪枝策略（Q3 选 A：全组合+剪枝）
- C(201,3) = 1,313,400 组合。三重剪枝：
  1. 单卡预打分：每卡独立算四维子分（201 次），排序后仅 Top60% 卡入组合池（120 卡）
  2. 星线和约束：三卡平均星 ≤3.5（防全 5 星不可运营）
  3. 同 tag 去重：组合内 ≥2 卡同 effect_tag 降权（多样性惩罚）
- 剪枝后候选约 120^3/6 ≈ 28.8 万组合，纯 Python 评分 ~1ms/千组合 - 预计 5s 内
- 若实测超时：降级 Top50% 卡池（100 卡）- 16 万组合

## 5. 阶段策略说明生成

三段式模板（前期/中期/后期），由卡组 tags 驱动：
- economy 主导 - 前期攒钱；combat 主导 - 中期发力；trait-bridge - 后期成型
- 说明文案从 tags-策略段映射表生成，非自由文本（可控、可测）
