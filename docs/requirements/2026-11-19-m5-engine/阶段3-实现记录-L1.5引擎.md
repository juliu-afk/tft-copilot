## 关键实现决策

### D1：EquipsBook 索引初始化

frozen dataclass 的 `_index` 用带默认值字段 + `__post_init__` 惰性构建（`field(default=None)` + `object.__setattr__`），避开 property 无 setter 问题。比 M4 CardsBook 方案更简洁，后续库可复用此模式。

### D2：面板三轴与战力分并存

PanelEngine（对位引擎输入，三轴细粒度）与 PowerScorer（HUD 战力条，单分数）并存不替代——消费场景不同。两者共享单子能量口径 `(hp+10*ad)/1000` 与满配基准（star3 均值×10），M6 校准后可评估合并。

### D3：降级链双输入签名

`predict_l15(my_panel, opp_panel, my_power, opp_power, my_ctx, opp_ctx)`——panel 缺席时用 power 分数走 L0。engine.py 侧先 assemble 两侧 panel，再一次性调用，保证 L0/L1.5 切换零分支泄漏。

### D4：断点乘区替代激活数近似

羁绊增益从 M3 的 `sum(min(count,6))*1.5` 升级为逐羁绊 `breakpoint_weight(active)` 乘区（dps×(1+0.08w)、ehp×(1+0.06w)）。斗士(4) 与斗士(2) 现在面板可区分（测试 test_trait_breakpoint_distinction 验证）。

### D5：quadrant 双口径兼容

all_predictions 返回四元组（winrate/confidence/actual/engine），quadrant_summary 用 `row[3] if len(row)>3` 兼容 M3 三元组旧调用。L1.5 子集独立一行输出判错率。
